# Blue Archive spine viewer

This is a fan-made viewer for Blue Archive. The viewer recommended a desktop computer with Chrome.

demo: https://asdfdsa12.github.io/BA-Spine-Viewer

# Supporting viewer

* Standing Illust(& dummy/legacy)
* Memorial Lobby & Story Live2d

# Feature

* Voice select (KR, JP, CN), default: JP
* Control the spine parts transparency
* Korean subtitle
* Spine image download
